# JobHuntingU Website

Welcome to the official repository for the JobHuntingU website. This platform includes a React frontend, a Node.js backend, a Python-based RAG chatbot, and a MySQL database—all orchestrated with Docker.

## 📖 Quick Links
- **[Developer Handbook](./DEVELOPER_HANDBOOK.md)**: Everything you need to know about the tech stack, local setup, and deployment.
- **[Admin & Content Guide](./ADMIN_GUIDE.md)**: How to manage leads, jobs, blog posts, and website text.

## 🚀 Fast Start (Local)
1.  Clone this repo.
2.  Create a `.env` file in the root (see `.env.example`).
3.  Run `docker compose up --build`.
4.  Visit `http://localhost:3000`.

## 🌐 Production
- **URL**: [jobhuntingu.com](https://jobhuntingu.com)
- **Host**: Hostinger VPS
- **Deployment**: Automatic via GitHub Actions on push to `main`.
